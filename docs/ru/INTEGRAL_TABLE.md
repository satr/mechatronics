## 1. Степени и логарифм

| Формула | Условия и пояснения |
| --- | --- |
| $\int 1\ \mathrm{d}x=x+C$ | все действительные $x$ |
| $\int x^n\ \mathrm{d}x=\frac{x^{n+1}}{n+1}+C$ | $n\ne-1$; учитывай область определения действительной степени |
| $\int\frac{1}{x}\ \mathrm{d}x=\ln\lvert x\rvert+C$ | $x\ne0$ |

## 3. Тригонометрические функции

| Формула | Условия и пояснения |
| --- | --- |

## 4. Рациональные выражения и обратные тригонометрические функции

| Формула | Условия и пояснения |
| --- | --- |
| $\int\frac{1}{1+x^2}\ \mathrm{d}x=\arctan x+C$ | все действительные $x$ |
| $\int\frac{1}{\sqrt{1-x^2}}\ \mathrm{d}x=\arcsin x+C$ | $\lvert x\rvert<1$ |
| $\int\frac{1}{a^2+x^2}\ \mathrm{d}x=\frac{1}{a}\arctan\frac{x}{a}+C$ | $a>0$ |
| $\int\frac{1}{a^2-x^2}\ \mathrm{d}x=\frac{1}{2a}\ln\left\lvert\frac{a+x}{a-x}\right\rvert+C$ | $a>0$, $x\ne\pm a$ |
| $\int\frac{1}{\sqrt{a^2-x^2}}\ \mathrm{d}x=\arcsin\frac{x}{a}+C$ | $a>0$, $\lvert x\rvert<a$ |

## Проверка

Чтобы проверить формулу, возьми производную правой части. Для степенной функции это обратная операция к правилу производной степени.

Аргумент логарифма должен быть безразмерным: здесь x считается безразмерным, если не задан масштаб. Используй формулу только в указанной области определения.

<a id="section-6"></a>
## 6. Как выбирать формулу и проверять ответ

Сначала определяем переменную интегрирования после символа дифференциала (dx, dt или dθ). Коэффициент считаем постоянным только тогда, когда он действительно не зависит от этой переменной. Для неопределённого интеграла добавляем C, для определённого находим первообразную F и вычисляем F(b) − F(a). Проверяем ответ дифференцированием.

### Разобранный пример A — перемещение из скорости

В простой модели оси v(t) = 3 mm/s + (4 mm/s²)t за 0–2 s интегрируем каждый член:

$$
\int_0^{2\ \mathrm{s}}\left(3\ \mathrm{mm/s}+(4\ \mathrm{mm/s^2})t\right)\mathrm{d}t
=\left[(3\ \mathrm{mm/s})t+(2\ \mathrm{mm/s^2})t^2\right]_0^{2\ \mathrm{s}}
=14\ \mathrm{mm}.
$$

Ответ 14 mm, а не 14 mm/s. Интегрирование скорости по времени даёт перемещение.

### Разобранный пример B — работа переменной силы

Пружина F(x) = kx, k = 200 N/m, растяжение от 0 до 0.01 m:

$$
\int_0^{0.01\ \mathrm{m}}(200\ \mathrm{N/m})x\ \mathrm{d}x
=\left[(100\ \mathrm{N/m})x^2\right]_0^{0.01\ \mathrm{m}}=0.01\ \mathrm{J}.
$$

Получаем 0.01 J. Интеграл силы по перемещению — работа; умножать конечную силу на весь путь неправильно.

### Разобранный пример C — логарифм из простой зависимости

Первообразная 1/x равна ln|x|. Для безразмерного x от 1 до 2:

$$
\int_1^2\frac1x\ \mathrm{d}x=[\ln x]_1^2=\ln2-\ln1=\ln2\approx0.693.
$$

Ответ ln 2 ≈ 0.693. Это не логарифм длины в метрах: x безразмерен.
