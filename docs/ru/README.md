## Краткое повторение

Изучайте одну короткую тему, воспроизводите расчёт, запускайте программу в автономном режиме и объясняйте результат своими словами. Идеализированная модель не является проверенной моделью реального устройства.

При первом упоминании технического понятия рядом в скобках приводится английский термин.


В главах есть графики и диаграммы. Выводы 4t и 63.2 % находятся по ссылкам в конце соответствующих глав.
