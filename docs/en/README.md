## Study approach

Read one short section, reproduce its calculation, run the corresponding offline Python example, and explain the result in your own words. Distinguish the idealized model from the real physical system. Read the assumptions before reusing any equation.

The same chapters are also available in French, German, Italian, Spanish, Portuguese, Simplified Chinese, Japanese, Norwegian Bokmål, and Russian. All internal learning links above stay within the English edition.

The optional appendices in each lesson contain more advanced derivations and limits, linked from the introductory sections.


The lessons include diagrams and plotted numerical examples. For the origins of 4t and of 63.2 %, follow the **Further details** links in each chapter.
